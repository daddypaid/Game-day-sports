Sportsbook TEST MODE flow

  1. Customer opens GameDay Sportsbook.
  2. Browser requests controlled odds/live data.
  3. Customer selects a supported market.
  4. Server revalidates a fresh quote.
  5. Atomic placement records wager, selections and test-wallet debit.
  6. Scheduled settlement grades supported markets and applies any test-wallet credit.

Casino TEST MODE flow

  1. Signed-in customer opens a connected casino game.
  2. Browser invokes the authenticated game Edge Function.
  3. Trusted server logic determines the game result.
  4. Server-side wallet logic applies the test debit/payout atomically.
  5. Round/hand/spin history is persisted for the authenticated user.
  6. Operator analytics consume aggregate activity without presenting it as real revenue.
Security boundaryBrowser roles do not receive service-role keys or upstream provider secrets.
